##PYTHON LANGUAGE PROJECTS
  A collection of Python scripts demonstrating basic programming concepts, image processing, and functional logic.

 #Project Contents
  1) crop_image.py: A script using the Pillow library to crop images to specific coordinates and save the output.
     Pre-requisites:
     Install Pillow library for image scripts; [ pip install pillow ]
     Running Scripts:
     Open your terminal in this directory then run using this script (python crop_image.py)
     Image Processing: The crop_image.py script currently outputs a file named cropped_output.jpg.

  2) Functions.py: Examples of how to define and call basic Python functions.

  3) calculator.py: A basic calculator implementation for arithmetic operations.

  4) boolean.py & UserInput.py: Scripts demonstrating logical operators and handling user console input.

  NOTE
  This repository is updated regularly as new python concepts are explored.
