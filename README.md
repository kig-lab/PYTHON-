##PYTHON LANGUAGE PROJECTS
  A collection of Python scripts demonstrating basic programming concepts, image processing, and functional logic.

 #Project Contents
  crop_image.py: A script using the Pillow library to crop images to specific coordinates and save the output.

  Functions.py: Examples of how to define and call basic Python functions.

  calculator.py: A basic calculator implementation for arithmetic operations.

  boolean.py & UserInput.py: Scripts demonstrating logical operators and handling user console input.

  NOTE
  This repository is updated regularly as new python concepts are explored.
