##PYTHON LANGUAGE PROJECTS
  A collection of Python scripts demonstrating basic programming concepts, image processing, and functional logic.

 #Project Contents
  1) crop_image.py:
   A script using the Pillow library to crop images to specific coordinates and save the output.
     Pre-requisites:
     Install Pillow library for image scripts; [ pip install pillow ]
     Running Scripts:
     Open your terminal in this directory then run using this script (python crop_image.py)
     Image Processing:
     On running, the user can see the image first upon inputting the image path
     The features are cropping, rotating and resizing of the image which can be done simultaneously on one image

  4) Functions.py: Examples of how to define and call basic Python functions.

  5) calculator.py: A basic calculator implementation for arithmetic operations.

  6) boolean.py & UserInput.py: Scripts demonstrating logical operators and handling user console input.

  7)Imports.py: Basic knowledge on how imports work in python. 

  NOTE
  This repository is updated regularly as new python concepts are explored.
